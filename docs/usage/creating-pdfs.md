Browsershot will save a pdf if the path passed to the `save` method has a `pdf` extension.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
// a pdf will be saved
Browsershot::url("https://example.com").save("example.pdf")?;
# Ok(())
# }
```

Alternatively you can explicitly use the `save_pdf` method:

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
Browsershot::url("https://example.com").save_pdf("example.pdf")?;
# Ok(())
# }
```

You can also pass some html which will be converted to a pdf.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html).save_pdf("example.pdf")?;
# Ok(())
# }
```

If you need the base64 version of a PDF you can use the `base64_pdf` method. This can come in handy when you don't want to save the PDF on disk.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
let base64_data = Browsershot::url("https://example.com")
    .base64_pdf()?;
# Ok(())
# }
```

## A note on security

It is the responsibility of the user to validate the URLs and HTML passed to browsershot. Only pass URLs and HTML that you trust.

Local file requests from `html()` are blocked by default. If your trusted HTML needs local assets, explicitly opt in with `allow_local_file_access(true)`. See [local file access](/docs/browsershot-rust/v1/usage/introduction#content-local-file-access) for details and security considerations.

## Sizing the pdf

You can specify the width and the height.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
# let width = 640.0;
# let height = 480.0;
Browsershot::html(some_html)
   .paper_size(width, height)
   .save("example.pdf")?;
# Ok(())
# }
```

Optionally you can give a custom unit to `paper_size_with_unit` as the third parameter, using `Unit::Mm`, `Unit::Cm`, `Unit::In` or `Unit::Px`.

## Using a predefined format

You can use the `format` method and provide a format size:

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
Browsershot::url("https://example.com").format("A4").save("example.pdf")?;
# Ok(())
# }
```

The available `format` options are:

```text
Letter: 8.5in  x  11in
Legal: 8.5in  x  14in
Tabloid: 11in  x  17in
Ledger: 17in  x  11in
A0: 33.1in  x  46.8in
A1: 23.4in  x  33.1in
A2: 16.54in  x  23.4in
A3: 11.7in  x  16.54in
A4: 8.27in  x  11.7in
A5: 5.83in  x  8.27in
A6: 4.13in  x  5.83in
```

## Setting margins

Margins can be set.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
# let top = 10.0;
# let right = 10.0;
# let bottom = 10.0;
# let left = 10.0;
Browsershot::html(some_html)
   .margins(top, right, bottom, left)
   .save("example.pdf")?;
# Ok(())
# }
```

Optionally you can give a custom unit to `margins_with_unit` as the fifth parameter.

## Headers and footers

By default a PDF will not show the header and a footer generated by Chrome. Here's how you can make the header and footer appear. You can also provide a custom HTML template for the header and footer.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
   .show_browser_header_and_footer()
   .header_html(some_html)
   .footer_html(some_html)
   .save("example.pdf")?;
# Ok(())
# }
```

In the header and footer HTML, any tags with the following classes will have its printing value injected into its contents.

* `date` formatted print date
* `title` document title
* `url` document location
* `pageNumber` current page number
* `totalPages` total pages in the document

To hide the header or footer, you can call either `hide_header` or `hide_footer`.

## Backgrounds

By default, the resulting PDF will not show the background of the html page. If you do want the background to be included you can call `show_background`:

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
   .show_background()
   .save("example.pdf")?;
# Ok(())
# }
```

If you want a transparent background color instead of the default white, you can call `transparent_background`:

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
   .transparent_background()
   .save("example.pdf")?;
# Ok(())
# }
```

## Scale

Scale can be set. Defaults to 1. Scale amount must be between 0.1 and 2.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
    .scale(0.5)
    .save("example.pdf")?;
# Ok(())
# }
```

## Only export specific pages

You can control which pages should be export by passing a print range to the `pages` method.  Here are some examples of valid print ranges: `1`, `1-3`,  `1-5, 8, 11-13`.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
   .pages("1-5, 8, 11-13")
   .save("example.pdf")?;
# Ok(())
# }
```

## Set the initial page number

You can set the initial page number with `initial_page_number`. Here's an example that shows how to set the first page to number 8.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
# let some_html = "<h1>Hello world!!</h1>";
Browsershot::html(some_html)
   .show_browser_header_and_footer()
   .hide_footer()
   .header_html("<span class=\"pageNumber\"></span>")
   .initial_page_number(8)
   .save("example.pdf")?;
# Ok(())
# }
```


## Output directly to the browser
You can output the PDF directly to the browser using the `pdf()` method.

```rust,no_run
# use spatie_browsershot::{Browsershot, ClickOptions, Polling};
# use std::time::Duration;
# use serde_json::json;
# fn main() -> Result<(), Box<dyn std::error::Error>> {
let pdf = Browsershot::url("https://example.com").pdf()?;
# Ok(())
# }
```
